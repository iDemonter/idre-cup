# API сервера Idre Cup

Все ответы в JSON. Ошибка: `{ "error": "код", "message": "текст по-русски" }`.
Запросы участника подписаны токеном устройства: `Authorization: Bearer <токен>`. Токен выдаётся один раз, при создании кубка или входе; в базе лежит только его хеш.

| Запрос | Кто | Что делает |
|---|---|---|
| `GET /health` | все | Сервер жив, база отвечает |
| `GET /v1/config` | все | Правила и очки (`config/rules.json`) |
| `POST /v1/cups` `{cupName, name, startsOn?, prize?, geofence?}` | все | Создаёт кубок и его админа. Ответ: `cup`, `me`, `token` |
| `POST /v1/join` `{code, name}` | все | Вход по коду приглашения. Ответ: `cup`, `me`, `token` |
| `GET /v1/me` | участник | Кубок, я, список участников |
| `PATCH /v1/cup` `{home}` | участник | Общее жильё: `{lat, lon}` или `null` |
| `PATCH /v1/cup` `{name?, startsOn?, prize?, geofence?}` | админ | Настройки кубка |
| `POST /v1/cup/code` | админ | Новый код приглашения, старый перестаёт работать |
| `PATCH /v1/participants/:id` `{name}` | сам участник или админ | Переименовать |
| `DELETE /v1/participants/:id` | админ | Удалить участника из кубка |
| `POST /v1/participants/:id/admin` | админ | Передать права админа |
| `POST /v1/participants/:id/restore` | сам участник или админ | Одноразовый код возврата на сутки |
| `POST /v1/restore` `{code}` | все | Вход по коду возврата с нового телефона. Старый телефон отключается |
| `PUT /v1/me/avatar` (тело: JPEG или PNG до 300 КБ) | участник | Свой аватар. Ответ: `{avatar: версия}` |
| `DELETE /v1/me/avatar` | участник | Убрать аватар |
| `GET /v1/participants/:id/avatar` | участник того же кубка | Картинка аватара |
| `POST /v1/tracks` `{points: [[t, lat, lon, alt, speed, acc], ...]}` | участник | Точки GPS, до 5000 за раз. Повтор тех же точек безвреден |
| `GET /v1/tracks/last` | участник | До какого времени сервер знает мой трек |
| `GET /v1/day?date=2027-01-03` | участник | Рейтинг дня: скорость, объём, места и очки. Без даты: сегодня |
| `GET /v1/standings` | участник | Общий зачёт по дням кубка |
| `GET /v1/live` | участник | Последняя точка каждого участника за 15 минут |

## Как считается день

1. Берутся точки участника за день по времени кубка (`timezone`, по умолчанию Europe/Stockholm).
2. Если у кубка включена территория (`geofence`), остаются точки не дальше 4,5 км от вершины Idre Fjäll. Для проверки дома территорию можно выключить.
3. Трек разбирается на спуски и подъёмы (`src/analyzer.js`, тот же алгоритм, что в приложении).
4. Скорость: лучшая на спусках, которую держал 3 секунды. Объём: перепад, число спусков и дистанция, каждая как доля от лучшего за день.
5. Места дают очки 10/7/5/3/1 в каждом из двух зачётов. В последний день кубка очки удваиваются.

Демо-кубок для проверки приложения: `node tools/seed-demo.js http://127.0.0.1:8080`.

Короны, автогонки, дуэли и события добавятся позже.
