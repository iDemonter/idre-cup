# Idre Cup — правила для работы с репозиторием

Приложение для iPhone (SwiftUI, минимум iOS 18.1), сервер на Node. Что где лежит — в `README.md`. Интерфейс и тексты — на русском.

## Дизайн: сначала Figma, потом код (с 16.11.2026)

Figma отвечает за то, как выглядит; спецификация ([docs/spec.md](docs/spec.md)) — за то, как работает. Изменение поведения — сначала в спецификацию.

Файл: https://www.figma.com/design/acerhjwP1YhbPlMWSAF0qy — страницы «Основа» (токены), «Компоненты», «Экраны — сейчас», «Экраны — предложения», «Архив».

Любой новый экран или изменение интерфейса:

1. Сначала макет в Figma из готовых компонентов страницы «Компоненты». Нужен новый компонент — сначала он появляется на странице «Компоненты» (имя = имя будущей SwiftUI-вьюхи), потом используется в макете.
2. Потом код. Цвета, шрифты, отступы и радиусы — только из `app/Shared/Design/Tokens.swift` (`Palette`, `Typo`, `Spacing`, `Radius`), без захардкоженных значений. Новый токен — сначала переменная или стиль в Figma, затем `design/tokens.json` и `node design/generate-tokens.js`.
3. После сборки сверить снимок из ветки `screenshots` с макетом. Расхождение — исправить код или обновить макет, чтобы они снова совпадали.
4. Обновить `design/COMPONENTS.md`: компонент → файл в коде → ссылка на узел Figma.

Рамки дизайна: один акцентный цвет (`accent`; текстом — `accentText`), игровой стиль, SF Pro Rounded, значки только SF Symbols, только iPhone, светлая и тёмная тема. Стекло (Liquid Glass) — с запасным видом для iOS 18 (`.glassBackground(in:)`). На стекле — только `textPrimary` и `accentText`. Зоны нажатия от 44 pt.

## Работа с кодом

- Mac нет: сборка и снимки экрана — GitHub Actions на `macos-26` (`.github/workflows/ios.yml`). Снимки последней сборки — ветка `screenshots`.
- Коммитить и пушить — только когда об этом просят. С `main` сначала создать ветку.
